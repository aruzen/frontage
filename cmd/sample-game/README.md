# sample-game

既存のFrontageエンジンを使って、カードの召喚・魔法・戦闘を試すローカルPvEサンプル。ターミナルで操作し、NPCが自動で応答する。

## 起動

リポジトリ直下で実行する。この試作のworktreeは `worktrees/sample-game`。

```sh
cd worktrees/sample-game
go run ./cmd/sample-game -seed 1
```

すでにsample-gameのworktreeにいる場合は `go run ./cmd/sample-game` のみで起動する。

両側の自動対戦:

```sh
go run ./cmd/sample-game -auto -quiet -seed 1
```

`-quiet` を外すと、操作ログと各手番の盤面も表示する。`-seed` で山札の順番を変更できる。

## 操作

| コマンド | 内容 |
| --- | --- |
| `play 1 B4` | 手札1番をB4へ使用。召喚・単体魔法 |
| `play 1` | 全体魔法・ドローなど対象指定のないカード |
| `play 1 B4 E2` | 転移カードでB4の味方をE2へ移動 |
| `move B4 B3` | 味方ユニットを上下左右に1マス移動 |
| `attack B2 C2` | 射程内の敵へ攻撃 |
| `end` | 手番を終了し、NPCの操作を実行 |
| `hint` | 現在の状態からおすすめの操作を表示 |
| `board` / `hand` | 盤面・手札を再表示 |
| `cards` | 全カードを表示 |
| `auto` | 残りの対戦を両側自動操作 |
| `help` / `quit` | ヘルプ / 終了 |

最初に召喚と再行動を試す例:

```text
play 1 B4
play 3 B4
move B4 B3
end
```

手札番号は使用後に詰め直される。2行目は「疾風」で、召喚したばかりの前衛兵をすぐ行動可能にする。

## このサンプルのルール

- 5×5盤面。あなたのコアはC5、NPCはC1。相手コアのHP20を0にすると勝利。
- 各カード2枚の24枚デッキ。初期手札は前衛兵・射手・火球・疾風・叡智の5枚で、残りをシャッフルする。
- 召喚は自分側の2列の空きマスへ。各側ユニット6体まで。召喚直後は行動済み。
- ユニットは自分の手番に移動か攻撃を1回。移動は上下左右、射程はマンハッタン距離。射手は射程2で、射線の遮蔽判定はない。反撃も行わない。
- 初回マナ4。自分の手番ごとに最大値を1増やして全回復し、上限10。初回以外は1枚ドロー。
- 手札上限8。満杯のときの追加ドローはスキップする。空の山札からのドローは、手札枚数によらずコアへ1、2、3…と増える疲労ダメージ。
- 氷結は次の所有者の手番を1回止める。疾風で解除できる。転移は行動回数を消費・回復しない。
- 使用カードは使用済み領域へ置き、召喚された駒は別のUUIDを持つ。HPが0以下の駒は操作の効果をすべて解決した後に死亡処理する。
- 100手番経過で引き分け。1手番の操作は32回まで。

これらは効果の動作確認用に決めたサンプルのルール。通常のサーバーPvEのルール・パケット仕様とは独立している。

## カード

| カード | コスト | 効果 |
| --- | ---: | --- |
| 前衛兵 | 1 | HP4・攻撃2・射程1 |
| 森の射手 | 2 | HP3・攻撃2・射程2 |
| 石の守護者 | 3 | HP7・攻撃2・射程1 |
| 火球 | 2 | 敵1体に4ダメージ。コア可 |
| 癒やしの泉 | 1 | 味方1体を4回復。初期HPが上限、コア可 |
| 鼓舞 | 1 | 味方ユニットの攻撃力+2 |
| 火炎嵐 | 4 | 敵全体・コアに2ダメージ |
| 叡智 | 1 | 2枚ドロー |
| 吸魂 | 3 | 敵へ3ダメージ、自分のコアを3回復 |
| 疾風 | 1 | 味方ユニットを再行動可能にし、凍結を解除 |
| 氷結 | 1 | 敵ユニットの次の手番の行動を止める |
| 転移 | 1 | 味方ユニットを任意の空きマスへ移す |

定義は `internal/samplegame/cards.go`。コスト・能力値・効果説明をまとめてある。

## 実装と確認

召喚・移動・攻撃・HP/攻撃力変更・ドロー・死亡は、既存のActionとEventSystemで解決する。行動消費量の変更はサンプル用Actionで実装した。

所有権・コスト・範囲・配置先・手札上限・手番開始・勝敗は `internal/samplegame` が担当する。各操作はコピー上で処理し、成功時に確定する。NPCもコピー上で合法な操作を1手先まで比較し、元の盤面・手札・凍結・統計を変更しない。

```sh
go test -race ./...
go test ./internal/samplegame -run TestAutoplayCompletesWithRealCombat -v
```

12種類の効果、無効操作の原状維持、召喚酔いと再行動、凍結の期間、死亡と勝敗、手札上限、疲労、NPCの試行分離、CLI操作を検証する。シード1・2・3・7・42・99の自動対戦では、双方の勝利と全12種類のカード使用を確認している。
